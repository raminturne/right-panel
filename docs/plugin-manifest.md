# Manifest v1
```json
{"manifest_version":1,"api_version":1,"id":"hello-world","name":"Hello World","version":"1.0.0","entry":"index.html","permissions":["storage"]}
```
Required fields are `manifest_version`, `id`, `name`, `version`, and `entry`. Optional: `description`, `author`, `homepage`, `icon`, `permissions`, and `settings`. Setting types are `boolean`, `text`, `number`, and `select`.
